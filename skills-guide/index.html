My Claude Home Base — Skills Reference

Every tool available for building client projects (websites, apps, branding, launches), organized by the kind of work it's for. FREE = ready to use now, no signup. ACCOUNT = needs a free/paid account with that company first.

1. Starting a new project

The very first step, before any design or code — do this for every brand new client.

SkillWhat it doesHow to trigger it
client-intake FREEOur custom skill: asks a consistent set of starter questions (business basics, scope, brand, deadline, domain) so nothing gets missed on a new project, then sets up the project folder."new client, a dentist office" / "starting a project for a CPA"

2. Design & UI — making it look good

Use for any client site, app, or mockup where the look/feel matters.

SkillWhat it doesHow to trigger it
frontend-design FREEPushes me to write polished, non-generic looking UI — better spacing, color, type choices — instead of default "AI-looking" pages.Runs automatically whenever I'm building/styling UI. No magic words needed.
superdesign FREEA visual design canvas — mock up a page, flow, or marketing graphic before any code exists. Can also copy the style of a live website."design a homepage for..." / "redesign this like [site]" / "make a flyer for..."
redesign-existing-site FREEOur custom checklist for safely modernizing a client's old site without losing content."redesign this old site" / "modernize my client's website"

3. Building the site (frontend code)

The actual coding help for websites, once design is settled.

SkillWhat it doesHow to trigger it
vercel:nextjs FREEExpert guidance for building sites with Next.js (a common modern web framework) — routing, pages, data.Just ask normally — "build a page that shows..." — triggers automatically in a Next.js project
vercel:shadcn FREEReady-made, good-looking UI building blocks (buttons, forms, menus) so you're not designing every piece from zero."add a shadcn component for..." / happens automatically when adding UI
vercel:react-best-practices FREEAuto-checks your React code quality after edits — hooks misuse, accessibility, performance.Runs automatically after editing multiple component files

4. Backend & data — logins, forms, storage, bookings

Any time a client's site needs to REMEMBER something (a contact form, patient intake, appointment, login).

SkillWhat it doesHow to trigger it
firebase ACCOUNTOne-stop backend: user logins, a database, file storage, hosting — good default for small client backends.Just ask directly — "set up a contact form that saves to a database" / "add login to this app"
vercel:auth FREEGuidance for adding a proper login system (Clerk/Auth0/Descope) to a site."add user login to this site"
vercel:vercel-storage FREEGuidance for file storage or a real database (Postgres/Redis) when Firebase isn't the right fit."where should I store [files/data] for this client"

5. Client self-editing (so they stop needing you)

For low-tech clients who need to update announcements, events, hours, or photos themselves after you're done.

SkillWhat it doesHow to trigger it
sanity ACCOUNTGives the client a dead-simple "edit my website" screen for just the specific things you set up (e.g. Announcements, Events) — click on the live page, change it, save. No code, no dashboard clutter, nothing else exposed."set this client up to edit their own announcements" / handled automatically as part of `client-intake` when self-editing is needed

6. Mobile apps

For the "apps" part of your services — one build that works on iPhone and Android.

SkillWhat it doesHow to trigger it
expo-router FREEHandles screens/navigation in an app (like pages on a website, but for apps).Automatic once you're in an Expo app project
expo-native-ui FREEMakes screens look and feel genuinely native (iPhone-style), not like a website stuffed in an app."make this screen feel native" — or automatic while styling app screens
expo-design-system FREEKeeps one consistent set of colors/fonts/spacing across an entire client app."set up a theme for this app"
eas-app-stores ACCOUNTActually ships the finished app to the Apple App Store / Google Play."submit this app to the app store" (needs a paid Apple/Google developer account too)

7. Going live — deploy & domains

Turning a finished project into a real, working link a client can visit.

SkillWhat it doesHow to trigger it
ship-it FREEOur custom checklist: same safe steps every time to publish/update a live site, so nothing gets skipped."ship this" / "make it live" / "deploy this for the client"
vercel:deploy ACCOUNTActually pushes a project live on Vercel's hosting, with a real domain attachable."deploy this to Vercel" (needs a free Vercel account)
vercel:vercel-cli ACCOUNTCommand-line control over deployments, domains, and environment settings."check the deployment status" / "connect this domain"
netlify-skills ACCOUNTSame idea as Vercel, on Netlify instead — deploys, forms, functions, custom domains. Use this one since you already have a Netlify account."deploy this to Netlify"
domain-name-brainstormer FREEOur custom skill: helps pick (and checks availability of) a good domain name for you or a client."what domain should I use for this dentist site"

8. Winning & showing clients the work

Sales-side tools — before and after you build.

SkillWhat it doesHow to trigger it
pptx-generator FREEOur custom skill: builds a proposal/pitch-deck slideshow (as a slick webpage, opens like a presentation) for a prospective client."make me a proposal deck for the CPA office"
social-post-cards FREEOur custom skill: makes a properly-sized graphic for Instagram/LinkedIn/etc. to promote your services or a client launch."make an Instagram post announcing the new site"
digital-business-card FREEOur custom skill: builds a QR code digital business card — a mobile contact page with a "Save to Contacts" button, QR generated locally (no account, no cost)."make me a digital business card" / "build a QR business card for this client"

9. Quality & safety checks

Especially important for doctor/CPA clients — they handle private patient/financial info.

SkillWhat it doesHow to trigger it
security-guidance FREEFlags security mistakes (leaked info, unsafe forms) while I write code, plus a deeper check before you ship.Runs automatically while editing; or ask "check this for security issues"
code-review FREEA second pass over recent changes for bugs, not just security./code-review
